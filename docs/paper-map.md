# From the paper to the code

Where each part of the paper comes from. Paths are relative to the repo root.

## How results are produced

```
raw model runs  ->  per-item CSVs        ->  analysis scripts  ->  results_*.json  ->  tables and figures
(bbq_firstparty,    experiments/             experiments/*.py      experiments/        paper/tables
 natural_model_     lab_results/                                    (copied to          paper/figures
 screen)                                                            results/summaries)
```

`scripts/verify_paper_claims.py` reads the JSON and the generated `.tex` and compares them with the
text of the paper (`paper/main.tex` plus the files in `paper/sections/` and `paper/appendix/`).

## Tables and figures

All generated by `experiments/make_paper_assets.py`, except `fig_method`, which is drawn by hand in TikZ.

| File in `paper/` | Shows | Reads |
|---|---|---|
| `figures/fig_teaser` | one published result, before and after | `results/decap_decomposition.csv` |
| `figures/fig_method` | overview of both analyses | (hand-drawn) |
| `figures/fig_decomposition`, `tables/tab_decomposition` | coverage vs disposition for the 32 pairs | `results/decap_decomposition*.csv/json` |
| `figures/fig_identification` | Manski interval against measured rate | `results_bbq11_firstparty_summary.json` |
| `tables/tab_firstparty` | six-checkpoint BBQ results | `results_bbq11_firstparty_summary.json` |
| `figures/fig_variance`, `figures/fig_cells`, `tables/tab_bbq_by_category` | the 66 checkpoint x category cells | `results_bbq11_by_category.json` |
| `figures/fig_calibration`, `tables/tab_calibration_full` | false-positive rate by draw count | `draw_count_calibration.json` |
| `tables/tab_power_magnitude` | power by size of violation | `results_power_by_magnitude.json` |
| `tables/tab_certificate`, `figures/fig_abstention` | WinoGender certificate results, abstention lean | `results_n480_summary.json` |
| `tables/tab_violations` | every certified violation | `lab_results/violation_taxonomy_n480.json` |

GitHub results page and are not in the paper.
